# D40–D43：把修订指导交给下一位执行者

日期：2026-10-18。本文将修订路线、来源、责任和资料获取整理成可交接的操作。

## 交接一项具体请求

以请求、适用范围、当前路线和指南版本为中心。说明谁负责、采用哪些材料、每份材料用于哪一步，以及预期交付什么。路线可以是解释、重分析、验证、收窄主张或保留限制；在交接时说明它回答请求的哪一部分。

来源、实现和结果分别记录。任务已完成时，链接实际产物；计划或受阻工作按当前状态交接。需要获取来源材料时，先确定材料类型和取得方式，再选择公开数据库、仓库或已提供文件，按有界预算获取并记录结果。

## 先复盘再扩展

先用已有案例检查任务单是否能支持真实接手，再扩展到新的论文或研究方向。若领域方法仍需选择，补上具体选择条件和合法替代；增加字段本身不会替代这种指导。
