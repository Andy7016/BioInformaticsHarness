# D58：切换相关视角，重读后再修订

D53 区分取得与阅读，D55–D57 把地图范围、已读条件与正文论证连接起来。交付已经固定后，研究者仍可能围绕熟悉的分支补查，而读者需要的选择条件尚未充分表达。

本次在[方法取舍指南](../methods/guides/review-choice-synthesis.md)加入条件触发的重读路径：确认交付与版本，保留旧包，主动完整重读本轮实际依赖且与决定相关的原文，再复查遗漏、缺分析和注意分配，另存新稿。正文、方法、表图和图注按实际阅读说明；相关补充材料和预算不足下的未读范围继续可见。

四类提问分别关注用途与评价、信息用途与对象、比较条件、缺口与回应。视角按当前决定切换：从作者明确的目标和操作、受众实际用途及当前生信任务条件定位，再按具体不匹配展开。来自学科身份、提示或参照作者的关注点，要经过来源和适用性核对后才进入当前义务。注意分配偏窄按旧文与用途判断；统计学习中的过拟合另需数据与统计设计。

[AF2Complex 工作例](../../examples/research-support/preparation/choice-synthesis-example/rereading/README.md)使用既有真实材料，区分给定组分的结构质量与候选蛋白对筛选，并把两个任务的生成预算接进新正文。预算遗漏在此前独立复核中已经发现；本次将全文重读、保留正确论证、受限修订与已有地图消费串成可接手的例子。

实施复用 D53 账本、D55/D56 地图、既有封存和 revisor 路线。原稿、旧分数与原访问边界保留；交付接收、文件检查和科学接受分别记录。简短任务可以沿用一页表格或原平台；完整重读后也允许没有新遗漏。

本轮接受对象是维护指南与真实工作例。全文重读相对定向选段或提示的效率、以及研究总体成绩的变化，仍需合适的独立评价。实现、真实阅读范围与消费状态见[结构记录](../../machine/design/rereading-perspectives.json)。
