# 修订指导与验收

日期：2026-10-16。本文将具体修订回应作为当前设计方向，并以较早模型论文和修订案例检验指导。

## 目标

帮助研究者把生物学概念连到测量、数据单位、标签或代理、模型目标、评价和结论。收到请求后，读者应知道需要哪些输入、有哪些回应路线、应交付什么，以及如何判断结果支持到哪一步。

## 分开观察四件事

1. 指导是否容易找到、理解和沿来源追溯。
2. 指南是否提供适用于任务的操作和判断依据。
3. 方法或工具是否按预期执行并产出结果。
4. 结果是否支持科学主张。

一次完整复核可先选一项明确请求，从原文和方法定义出发安排回应，再查看交付物和结果。早期经典案例是理解修订过程的取样；其结果用于说明案例条件，不作为对年代或模型类别的预设评价。
