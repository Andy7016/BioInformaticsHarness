# 研究与验证计划

本文提出如何检验BioInformaticsHarness的研究问题。计划的几个核心实验和用户研究尚未启动。

## 可被结果推翻的问题

- **方法有效性：** 在相同模型、输入和计算资源下，方法指导是否减少严重的方法错误？
- **验证可靠性：** 检查工具能否发现形式完整但方法不适用的方案，同时接纳合理替代和诚实报告的不足？
- **研究可接手性：** 独立研究者能否依据研究包重建关键结果并定位缺失条件？
- **学习迁移：** 使用者在不再获得辅助时，能否在新数据或问题上更好地选择方法、识别混杂并解释结论？

不改善结论的结果也会影响设计。例如，指导只改变报告格式、严重错误没有减少、误拒合法替代，或有辅助时更好而迁移没有变化，都提示需要缩小或调整方案。

## 先做哪些试点

先选一个任务包，冻结研究问题、输入、方法和验收标准，再验证记录与检查工具是否帮助研究者做出正确选择。对系统本身的比较需匹配模型、资料和资源；科学任务执行、检查器校准和教学研究分别安排，避免把其中一项结果当作另一项的证据。
