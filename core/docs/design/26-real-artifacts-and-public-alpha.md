# D49：用真实工件检验方法指导

日期：2026-10-20。本文说明为何选用保存的S4PRED预测工件，以及公开研究原型的验收范围。

## 选择S4PRED作为条件案例

保存工件包括802行、五个模型成员的三类预测概率、配对参考与资格信息，适合研究置信排序如何影响候选使用。它能够支持一个真实的小型案例，让研究者将不确定性读出连接到比较、数值和适用范围。

新计算开始前，先说明纳入实体、排序、保留比例、比较参照和会改变决定的结果。类别构成等额外比较由具体替代解释触发，再决定是否加入，不作为所有置信研究的固定要求。

## 公开原型的范围

可公开的研究原型应有清楚的研究范围、可引用来源和可运行示例。科学研究覆盖、真实运行、他人复现、许可和分发内容分别说明。论文数量或工具测试不能代替实际研究使用与许可审阅。
