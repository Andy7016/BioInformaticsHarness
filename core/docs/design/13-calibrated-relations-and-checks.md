# 条件指导与研究关系

日期：2026-10-14。本文记录在既有研究对象之间补充关系记录的设计决定。

## 保留研究对象，补上重要联系

研究问题、数据快照、方法、运行、工件、比较、主张和复核仍是组织研究的核心对象。新增设计说明它们何时相关，以及应如何记录组件消费、阶段选择和数学聚合。

条件指导围绕具体选择展开：参考系或坐标如何变化、结构比较适用哪种几何对象、指标的数学事件怎样对应实际实现、配置如何在组件中生效。研究者按问题启用对应方法卡，并保留适用范围和合理替代。

关系记录可帮助团队查看声明输入与结果之间的连接。它输出的状态应结合所记录的资料范围解释；方法是否适合研究目标仍由研究者判断。
