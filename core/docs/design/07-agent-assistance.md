# 智能体协作与研究者交接

日期：2026-10-02。本文记录一种让智能体参与研究、同时让研究者保留判断权的设计方向。

## 三层职责

- **研究方向：** 明确问题、目标、适用条件以及哪些结果会改变判断。
- **方案设计：** 把研究意图转成案例相关的材料、方法、比较和交付物。
- **执行：** 调用工具、整理输入输出、报告运行情况，并将结果交回方案和研究问题。

方案层负责把技术产物转成可阅读的研究解释。研究者可以围绕解释追问并修改研究方向，不必先阅读每份底层日志。

## 交接方式

执行者收到一个具体任务、必要材料、输入用途和预期结果。完成后交付产物、所用条件、未完成事项和建议下一步。任务变更时更新研究决定及其影响，让下一位执行者知道哪些工作需要重新运行。

这一分工用于简化理解和协作，不预设某个模型、工具或部署架构。mRNABERT例子和交互细节见[机器文档记录](../../../machine/document-notes/core/docs/design/07-agent-assistance.md.json)；当前可用的交接入口见[研究操作工具](../methods/research-support-tools.md)。
