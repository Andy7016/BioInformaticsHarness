# 设计图景 v0.1

日期：2026-09-15。本文记录BioInformaticsHarness的初始产品方向。

## 目标

为生物信息学研究提供一个将研究问题、方法条件、可重建计算与结论依据连起来的工作环境。研究者可以了解为什么选择某项方法、输入如何进入分析、实际得到什么结果，以及结果支持到哪里。

## 工作方式

一次研究从问题和材料开始，经过方法选择、数据划分、执行、评价和解释，再交给下一位研究者复核。理论工作负责研究问题与方法判断；应用工作把研究意图变成针对当前案例的方案；执行工作调用工具并整理结果。人可以随时查看关键选择并修改方向。

系统围绕研究问题、数据快照、方法、决定、运行、工件、比较和主张组织记录。研究使用者可按需要进行探索、协议化评测或教学活动；同一界面应帮助读者理解研究，而非只呈现技术日志。

## 接下来

先用完整的论文案例检验这条工作路径，再决定哪些对象、接口和工具值得实现。各项工具选择仍应由试点问题和实际输入决定。
