# 从二十个案例中提炼阶段关系

日期：2026-10-14。二十项工作用于判断若干研究流程问题是否跨案例出现，并细化可复用的关系记录。

## 三类值得记录的联系

案例共同提示三类问题：对象从一个阶段如何被选择到下一阶段；标签、先验或参考在不同阶段怎样使用；结果工件如何被后续程序读取。它们是跨机制的工程关注点，不是对所有研究的共同缺陷。

因此保留原有研究对象，通过条件关系连接选择、信息用途和实际消费。只有研究涉及相应选择、独立性主张或文件消费时才记录该组；没有触发的研究不需要虚构阶段、资产或运行回执。合法开发性或传导式任务可以按其目标使用数据，但结论应与该用途一致。

选择记录应带有阶段、单位、规则和去向；信息记录应说明材料用于拟合、调参、选择还是评价；消费记录应分开说明文件读取与模型参数作用。
