# 从案例中细化工程指导

日期：2026-10-12。五个模型案例表明，通用研究对象可以整理问题、数据、方法、运行和主张，但具体操作往往依赖领域条件。

## 设计决定

在现有研究对象上增加条件化方法卡和交接指南，不增加同义的顶层对象，也不要求每项研究填写全部内容。每张指南应说明触发条件、所需输入、操作选择、判断依据、合理替代和结果如何影响主张。

真实案例还显示，只登记文件和模型名称不足以说明程序实际如何使用它们。因此，记录需要区分配置、输入、运行结果和产物消费；团队可根据影响结论的具体环节选择检查方式。

评议者应能沿着案例来源独立判断指南是否提供了可执行的选择，而不只评价文档是否完整。案例细分和验收来源见[统一索引](../../../docs/REFERENCES-AND-DESIGN.md)。当前方法卡从[研究问题导航](../methods/README.md)进入，完整决策原稿见[机器文档记录](../../../machine/document-notes/core/docs/design/11-case-driven-engineering-guidance.md.json)。
