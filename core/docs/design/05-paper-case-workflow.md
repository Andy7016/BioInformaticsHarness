# 用已发表论文检验研究流程

日期：2026-09-26。本文提出一个由论文案例逐步检验Harness设计的工作流。

## 为什么从论文开始

论文可以帮助研究者重建问题、方法、数据、评价和修订之间的关系。它是观察对象，作者的选择提供研究语境；研究团队还需要判断这些选择是否适用于新的问题，并保留合理替代。

## 工作顺序

1. 比较少量候选论文，选择材料相对完整且有清楚研究问题的案例。
2. 重建一篇论文的整体研究逻辑，再选一个主要结论追踪其数据和计算证据。
3. 为该结论设计小型复算或独立检查，并记录输入、方法、评价单位和结果。
4. 汇总哪些框架对象已能表达这些步骤、哪些实际选择仍需要条件化指导。
5. 依据案例中暴露的具体问题再决定接口或工具，而不先假定所有论文走同一流程。

研究流程图和软件对象图回答不同问题：前者帮助读者理解研究如何开展，后者说明工具如何保存记录。让二者相互链接，便于从科学问题找到可检查的产物。

## 如何比较不同路线

先描述作者报告的路线，再记录当前能检查的材料和拟议的替代。重建既有计算与支持原结论是两种不同任务；案例材料不足时，把需要的数据或方法列为后续工作。
