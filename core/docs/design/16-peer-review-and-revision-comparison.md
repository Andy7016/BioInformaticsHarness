# 把同行评审纳入修订工作流

日期：2026-10-15。本文说明如何用评审意见检验研究指导在真实修订中的作用。

## 比较单位

以一个具体 concern 和它所针对的稿件版本为单位。拆开包含多项要求的意见，保留提出者和上下文；同一问题在回应和后续轮次中的变化通过关系连接，而不是按段落数重复计数。

## 追踪回应

将评审关切、原稿方法与结果、作者选择的路线、修改产物和下一轮复核连起来。早期稿件和发表版本之间发生的变化会影响能回答的问题，因此记录它们各自的版本和关系。

指导的作用是帮助作者解释意见、选择补证或收窄主张，并组织可供审阅的结果。研究者仍需判断回复是否解决了 concern；相似主题本身不能证明指导已执行。
