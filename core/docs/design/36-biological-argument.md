# D59：把生物对象、特征、标签与用途接成论证

输入列、标签和分数能够分别核对时，研究者仍可能难以判断数值怎样来自生物对象，以及为何适合当前使用。本次沿既有[生物学解释指南](../methods/guides/biological-explanation-and-handoff.md#从对象到用途接通关系)补上中间的理由：对象怎样成为观测单位，观测怎样形成表示，标签为何能作参照，输出怎样支持候选动作与评价。

这些关系围绕当前决定展开。固定任务可以交付准确的局部效用结论；新用途按实际需要选择独立标签、新的划分或实验。上游学得的表示要解释来源，训练重合尚未核实则保留待核范围。对象辨认、历史标签命中、排序效用和机制各有相应证据。

[Yeast 工作例](../../examples/research-support/preparation/choice-synthesis-example/biological-argument/README.md)完整连接序列定位任务、八项历史特征、档案类别与固定预算排序。旧报告已清楚区分小写 vac、大写 VAC、模型分数和档案命中；本次补入特征形成和来源联系，保留固定状态下未达到收益门槛的负决定。AF2Complex 仅作短对照，说明给定组分的结构质量与候选蛋白对筛选为何需要各自的对象、参照与生成预算。

实施复用 D53 的来源账本、D55/D56 的问题地图及现有回应路线。工作例交付连续正文和可被现有消费者读取的最小记录；人工科学接受另行完成。来源位置、实际阅读、未读材料、版本与接受状态见[结构记录](../../machine/design/biological-argument.json)。本轮评价指南与有界工作例；指南对研究总体质量的影响仍需独立设计。
