# GitHub 仓库范围

2026-10-02：按用户要求准备将 Harness 本体纳入 GitHub，初始可见性为 private。仓库名默认采用 BioInformaticsHarness。当前项目仍处于设计与研究准备阶段，仓库不是已经实现的智能体运行平台。

## 纳入版本管理

保留项目设计、需求确认、参考蒸馏、案例契约、自己编写的脚本与检查程序，以及参考书目、来源清单和历史下载索引。设计历史继续保留，不因提交仓库而删除。

## 留在本地

原始 ChatGPT 对话、第三方论文全文及提取文本、下载的第三方源码与归档、集群连接和资源快照、生成的检查报告、模型权重与实验备份不上传。具体规则见根目录 `.gitignore`。忽略规则只控制版本管理，不删除本地资料。

现有设计和案例文档保留历史来源链接、实验说明及部分本地路径作为追溯记录；private 仓库不能被视为已完成公开发布审查。将来改为 public 前，应复审个人信息、历史来源、第三方引用与许可。当前不擅自选择开源许可证；第三方资料的权利仍归各自权利人。

## 克隆后的使用边界

仓库内可阅读设计、检查案例 JSON 和 Python 语法。原有资料核验脚本依赖本地参考库或备份：`validate_intake.py` 需要未上传的原始对话；`validate_distillation.py` 及静态源码证据检查需要下载资料；`check_rna_harness_case.py` 会检查本地来源路径，只有仓库文件时不能完整通过。这些缺失不能解读为科学验证失败，也不能默认为通过。

文档中指向忽略目录的链接是本地证据入口，纯 Git 克隆中不可用。下载清单和历史核验说明只记录当时的工作区状态，不宣称这些资产随仓库交付。后续可增加显式的资料恢复与可移植检查入口；本次不改写已有核验语义。
