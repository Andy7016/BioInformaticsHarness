# 公开代码库的内容范围

日期：2026-10-02。本文概述如何维护可独立使用的Harness代码库。

## 代码库中维护什么

保存项目设计、方法指南、原创脚本与检查工具、案例说明和相应来源清单。示例应说明哪些文件来自外部、如何变换以及适用的许可。发布的每项内容都应能从许可说明或案例清单找到出处。

## 研究档案与使用环境

完整研究档案可包含原始对话、第三方论文、源码包、实验记录、模型权重和环境信息。这些资料按自己的许可和用途维护；公开项目只包含经过选择并说明来源的材料。忽略文件规则只影响版本管理，不会删除本地资料。

在新环境中运行前，按quickstart安装所需依赖并选择独立输出目录。需要使用额外数据或模型时，先检查对应来源和许可，再将数据路径写入研究材料。

当前发布的使用说明见[core quickstart](../../QUICKSTART.md)和[许可指南](../../LICENSING.md)。更完整的历史范围与设计讨论见[机器文档记录](../../../machine/document-notes/core/docs/design/08-repository-scope.md.json)。
