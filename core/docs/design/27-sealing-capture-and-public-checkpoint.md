# D50：计划封存、首次执行记录与公开发布

日期：2026-10-21。本文记录三项帮助研究跨执行者交接和公开分发的决定。

## 计划与实际执行

- **封存研究计划：** 用明确的计划根目录解释清单路径，生成计划摘要，再按该目录收集文件并交付确认记录。旧协议需要明确选择。已有版本库、预注册服务或其他可靠封存系统可以替代。
- **记录首次重要执行：** 在首次影响清洗、样本纳入、划分或研究判断的真实审计前，保存计划中的代码、配置和输入信息；保留成功和失败结果。可信执行快照可以承担同样用途，日常浏览不需要完整执行包。
- **说明发布材料权利：** 发布者为每个文件列出许可来源和修改说明。混合含有项目训练参数与来源数据的工件按实际内容说明归属；外部材料也可保持不随包分发，改为链接来源或使用开放数据。

## 当前研究原型

公开包使用经过筛选的Git历史，并与完整研究档案分开维护。公开示例、第一方代码、原创说明和开放数据分别遵循各自许可。连续科学迭代应保留首次计划、实际补分析、结果变化和后续交付；证据没有改变结论时，说明理由并维持原结论。
