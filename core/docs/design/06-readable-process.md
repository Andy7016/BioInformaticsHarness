# 面向读者的研究过程说明

日期：2026-09-29。完整过程说明帮助没有参与实验的人理解研究选择和结论。

## 写作顺序

从研究问题与动机开始，说明为何选择当前方法，再依次介绍关键输入、划分、操作、调整、失败和结果。结尾说明结果支持什么、尚有哪些问题，以及接手者可以采取的下一步。

图表应帮助读者看清对象和操作之间的关系。流程图、序列图或前后对照都可以；实际观测、计算预测和人工示意要用合适的标题或图注区分。读者需要重建具体结果时，给出与图表对应的脚本和输入材料入口。

## 选择内容详略

过程说明覆盖会影响研究理解的决定、结果和外部依赖。重复日志与日常工具调用放在可检索记录中；正文用清楚的链接指向它们。这样读者既能快速理解，也能在需要时查看细节。

可读过程既能作为研究交付物，也能帮助团队内部交接。每项关键结论都应能回到测量和来源，未完成的步骤则说明它会影响哪项后续判断。
