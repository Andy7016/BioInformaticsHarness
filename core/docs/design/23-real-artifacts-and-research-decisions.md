# D46：真实工件、方法取舍与研究交接

日期：2026-10-19。本文将真实工件使用、标签更新和生物学解释整理为可复用指导。

## 三项决定

1. **从保存文件进入真实消费。** 生产者和消费者都使用研究实际产生的序列化材料，再检查ID、缺失值、嵌套结构和集合边界。团队可以复用成熟表接口、共享reader或已有同版本结果。
2. **分开选择标签来源和更新方式。** 比较新标签获取与模型更新的作用时，控制表示、用途和预算；同时报告目标域收益与可能的源域代价。简单校准可以是合理方案。
3. **解释数据如何支持生物学主张。** 逐层说明数据表示、观测对象、代理和测量读出，给出会改变结论的条件及下一步证据。

这些主题可沿用现有研究对象，不需要新增顶层概念。相关指南见[生产—消费接口](../methods/guides/artifact-producer-consumer.md)、[标签来源与更新](../methods/guides/label-source-and-update.md)和[生物学解释与交接](../methods/guides/biological-explanation-and-handoff.md)。案例和设计来源见[统一索引](../../../docs/REFERENCES-AND-DESIGN.md)及[机器文档记录](../../../machine/document-notes/core/docs/design/23-real-artifacts-and-research-decisions.md.json)。
