# D35–D39：把修订指导落实到路线与验收

日期：2026-10-16。本文记录如何将修订意见连接到实际任务、产物和回应范围。

## 五项设计细化

- **D35 测量到主张：** 说明研究问题、实际测量、单位、模型目标、评价事件、支持的主张和未解决事项。
- **D36 回应路线：** 将复合意见拆成原子请求；按输入和目标选择解释、重分析、验证、限缩主张或保留限制等路线。
- **D37 验收范围：** 将检查条件与任务、产物和执行记录联系起来，并把结构检查和科学判断分开记录。
- **D38 实际交接：** 用真实材料走通两个小型回应流程，观察任务能否被下一位执行者继续。
- **D39 反馈修订：** 用使用中的术语或定义误扩张来修正指导，使下一位读者能区分研究建议与已有证据。

这些步骤不要求每项工作都开展新实验。根据请求选择路线；若解释足以回答问题，保留该范围；若结论取决于新数据，则安排对应分析。
