# Research, design, and method navigation

The public checkpoint contains the design notes, method guides, and examples needed to understand and use this release.

- [Research history](../../docs/history/EVOLUTION.zh.md) explains how case observations shaped the current design.
- [Combined source and design index](../../docs/REFERENCES-AND-DESIGN.md) collects public references and the decisions they inform.
- [Method guide](methods/README.md) maps research questions to practical cards and examples.
- [Core quickstart](../QUICKSTART.md) shows the first commands to run.
- [Splice and Yeast examples](../../examples/) demonstrate consumption of saved model states.

The complete research archive is maintained separately. The machine catalog at [machine/archive-pointers.jsonl](../../machine/archive-pointers.jsonl) labels each archived locator as part of `private_archive`; those files are not included in this release. Use the public sources and methods linked above for work based on this checkpoint.
