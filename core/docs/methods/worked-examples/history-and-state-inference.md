# 从细胞标签与状态推断哪一层历史

这是文献启发的假设设计例。问题是：目前的数据支持共同克隆、分叉祖先关系，还是只支持状态之间的相似与可能变化？本例先选可观测的历史层次；RNA velocity 的动力学细节沿用已有的[动态过程工作例](dynamic-process-interpretation.md)。

## 让输入决定可回答的历史问题

| 实际输入与条件 | 合法的推断路线 | 与输入相符的评价 |
|---|---|---|
| 固定、可遗传的克隆标签与末端细胞状态 | 识别共同克隆或已知标记祖先的后代归属 | 标签检出、覆盖、碰撞及克隆归属；克隆内部顺序另需信息 |
| 可积累或带时间解析的记录，并有适用的记录模型 | 在记录假设下推断分支或部分顺序 | 根据实际可见信息评价边、分支或拓扑；独立真实边可得时检验其恢复 |
| 连续直接追踪 | 对实际观测到的个体/细胞时间关系建模 | 区分直接观测与插补片段；检验追踪丢失、漏采样和分裂事件处理 |
| 只有已知采样时间，未追踪同一细胞 | 将时间作为状态变化的外部约束 | 区分取样先后与真实祖先后代；评价时间约束下的状态关系 |
| 只有细胞状态快照 | 相似性、轨迹或 pseudotime | 方向依赖根节点或外部先验时说明其来源；评价状态关系及独立时间参照 |
| 有适用的 spliced/unspliced 等动力学输入 | 条件性的局部状态变化估计 | 检查动力学适用性与外部方向证据，按已有动态例实施 |

共享条码所支持的共同来源与克隆内的有向树边分开交付。未记录的中间节点、未分辨的分叉和缺失边保留为待定；树形图的美观程度不决定其历史真实性。

## 一次最小的比较怎样安排

先写下主张层次与输入来源。例如，只观察固定克隆标签时，可以比较不同标签处理对克隆归属的稳定性，再研究克隆与细胞状态的关系；此时无须要求不可见树边的“真值准确率”。

若有可解析历史的记录，另行明确记录生成过程、时间分辨率、遗漏、碰撞及测量误差。在相同可观测对象上比较候选方法；有真实边的子集与全体可观测记录分开报告。模拟可用于诊断特定记录假设，实际历史判断仍按观测和外部参照组织。

## 什么结果改变解释

同一状态分支由多个克隆组成时，保留状态趋同等解释；同一克隆出现在多个状态时，区分共同来源与状态可塑性。若记录覆盖不足以排序，只交付可分辨的共同克隆或部分关系。方向随根节点改变时，将该选择带回时间或外部证据，而不是按图形方向作生物学结论。

## 交给人的图与选择

图中分别绘制观测标签、推断关系和未定关系，标出方向信息来自记录、时间还是根节点假设。说明当前能回答的问题，以及补充哪种信息能把共同克隆推进为分支历史。人可以选择增加历史分辨信息、研究状态关系，或保留部分历史结论。
