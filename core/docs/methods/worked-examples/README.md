# 研究问题驱动的条件工作例

这些例子把现有方法卡接到具体的研究选择。按当前问题取用；来源、作者做法与新增建议分开，保留可改变结论的观察和合法替代。

| 当前研究问题 | 工作例 | 要形成的判断 |
|---|---|---|
| 整体分数高，是否包含当前任务需要的特异信息 | [共同信号与任务特异能力](common-and-task-specific.md) | 匹配信息条件，选择能区分共同解释与特异能力的比较 |
| 根据置信输出采用、保留或拒用预测 | [置信度到使用决定](confidence-to-decision.md) | 分清排序、区间校准和实际策略效用，各按用途验收 |
| 从快照推断变化方向、时间或轨迹 | [动态过程解释](dynamic-process-interpretation.md) | 连起观测、假设、推断和图形，决定解释及使用范围 |

各页给出适用问题、可选路线和会改变结论的条件。开始前先选最接近的研究问题，再联用相关方法卡。论文和设计入口见[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)。
