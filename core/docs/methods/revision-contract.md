# 研究修订：把请求连到回应和证据

这份指南适用于论文评审、报告修改和内部研究复核。它帮助团队把每项请求连接到选定的回应路线、工作任务、产物和最终主张。需要新增分析、模型执行或指标重算时，单独完成研究步骤，再把结果接回应答链。

常见路线包括：解释已有材料、重新分析、开展验证、收窄主张、保留限制，或提出有证据支持的回应。请求由多个问题组成时，先拆成可以单独回答的部分。若有几条可行路线，写明选择理由、所需工作和未解决的问题；没有采用的路线也记录原因。

## 建立可接手的回应

1. **保留请求出处。** 摘录原子请求，引用具体评审意见、报告段落、图表或数据位置。复合请求分别编号，方便检查覆盖情况。
2. **选择回应路线。** 说明这条路线回答请求的哪一部分、为何适用，以及还有什么缺口。解释、限缩主张或保留限制通常只需要相关原文和方法依据；重分析与验证需要各自的输入、分析步骤和结果。
3. **分配工作并说明输入用途。** 每项任务标明负责人、所用材料及其用途。已完成任务要能指向产物；计划中、受阻或状态未知的任务保持原状态。
4. **把产物连到主张。** 说明哪个回应、表格、图或分析支持哪项主张，并写出适用范围和限制。主张应有直接来源或产物作为依据。
5. **列出验收方式。** 写清检查内容、检查者、结果和所依据的回执。结构检查、文件阅读、程序运行和科学判断分别记录。

## 选择与解释结果

请求可以有多个替代路线，但当前工作应标出所选路线。未选路线不需要假装完成；写清理由即可。对照历史作者路线时，说明哪些材料来自作者报告，哪些是当前工作新增的观察或解释。

`completed`表示所需输入和产物已经记录；`planned`和`blocked`表示工作状态；`unknown`用于关键信息不足的情况。显式引用冲突或状态矛盾需要修正。缺少来源、版本、输入用途、产物或必要回执时，保留未知，不补写推测结果。

有限的记录检查可以发现引用、责任和文件关系问题。它通过只说明所检查的记录与材料范围；科学接受状态仍由研究者按测量、设计、运行和结论分别判断。缺少记录时，可补齐来源或产物、安排验证、缩小主张，或保留明确限制。

## 需要不同材料的路线

- **解释：** 提供请求原文、相关来源和术语或测量定义。回应应让审阅者能复述原意，并指出解释适用范围。
- **重新分析：** 提供数据、分析对象、预定读出和适用对照。保存分析脚本或可复核结果以及会改变判断的条件。
- **验证：** 先说明验证对象、独立参照、单位和结果解释，再开展运行或实验。验证结果应直接回答选定主张。
- **收窄主张或保留限制：** 列明现有证据支持到哪里、哪些问题尚未回答，以及哪些后续观测可以改变结论。
- **回应反对意见：** 引用支持材料，按事实、方法解释和未解决问题组织回应；避免把一种合理替代说成已执行结果。
