# 从模型现象到生物学解释，再到人可以接手的决定

版本 `biological-handoff-v1.1`，2026-10-20；[v1原件](../../ARCHIVE_POINTERS.md#archive-pointer-7a07761538779c2c)保留。来源为[Optimus I03/I04](../../ARCHIVE_POINTERS.md#archive-pointer-5fb676b7713e553a)及[S4PRED I04/P-C01](../../ARCHIVE_POINTERS.md#archive-pointer-665687661f2347ad)，并连接[可读过程](../../design/06-readable-process.md)、[功能与效用](function-and-utility-validation.md)和[生物学可视化](../../ARCHIVE_POINTERS.md#archive-pointer-609451a158fcd4cf)。

## 什么时候需要展开解释

研究者需要从“当前模型或策略更有用”推进到“为什么”“如何改设计”或“下一步验证什么”时启用。只比较固定任务效用且已准确限域时，可以止于效用结论；不自动追加机制任务。

即使只交付固定任务结果，当程序ID、“全长”“原生”等术语可能让人误认研究对象时，也应补一段对象说明。先让人知道分析的究竟是什么，再决定是否展开机制。

## 先把程序中的对象翻译给人

围绕本次结论需要的区别解释四件事：**对象的可读名称与来源；实际进入程序的范围；标签/观测覆盖；它与读者熟悉的生物学对象有什么已知关系**。用一小段或短表即可；已有可信数据字典或来源中的充分说明可以直接引用。

PDB场景中，“提交polymer entity序列全长”说明输入序列包含哪些位置；天然参考映射说明对应哪个参考区间；实验坐标覆盖说明哪些位置有结构观测；计分mask再决定哪些位置进入分母。四者不能只用一个“完整蛋白”名称带过。表达标签、截短、突变和设计身份可能帮助读者理解面板，但仅凭名称或并列分数不能判断它们造成了模型误差。

[S4PRED对象工作例](../../ARCHIVE_POINTERS.md#archive-pointer-d5e7d517fc7a8054)及[来源提取程序](../../../examples/s4pred/describe_entities.py)复用本轮已核字段：LC3B的提交截短记录与标签、HRP2的C64S和标签、nsp1的参考片段、ABLE的设计身份等。程序提取来源并计算明确的区间端点；文字说明这些字段用于辨认对象与解释范围。没有映射或字段为空时保留未知，不从缺字段推出天然完整，也不自动重建“正确天然序列”。

| 当前需求 | 为什么选择 | 合法替代与改判 |
| --- | --- | --- |
| 仅需澄清已分析对象 | 对照已有字段补名称、构建和范围，不改变输入、mask或原结果 | 可信数据字典/作者明确说明；未取得的关系写unknown |
| 构建身份会改变研究资格或目标 | 说明它为何影响当前问题，按已有选择规则判断，必要时另立研究修订 | 保持原面板并限域；另建有理由的新面板，不因已见分数悄悄删例 |
| 人需要理解单个高/低分 | 同时展示对象身份、参考/类别组成和分母，选择最能区分解释的下一证据 | 先做有依据的描述；不必立即作机制解释、同源搜索或结构预测 |
| 当前对象不是PDB蛋白构建体 | 使用本任务的操作单位，例如reporter变量区、细胞/供体或分子状态 | 按当前测量和用途解释；不套用PDB、UniProt、SIFTS字段清单 |

## 把解释变成可检查的选择

1. **先说清现象与读出。** 哪类对象、哪个体系、什么测量发生什么变化？区分标签、代理、直接观察和模型预测。MRL是由多聚核糖体分级读数估计的加载量；当前50nt变量区及reporter体系须保留，不直接扩写成所有mRNA的蛋白产量或体内功能。
2. **选一两个最有区分力的假设。** 从已读文献和当前现象给出理由，说明它能解释哪部分、解释不了什么。另列最接近的替代，如测量批次、子库设计约束、表示或校准失配。暂不寻找所有可能机制。
3. **在计算前写预测和改判。** 记录可观测变量、分层、方向或对比，以及出现什么结果应支持、修改或放弃当前解释。已经见过性能结果的后补分析须标明已知信息；不能追认成原研究预注册。
4. **从廉价但有辨识力的诊断开始。** 现有序列可计算组成/同聚物、已知motif及对应残差；先核ID、覆盖、稀疏项与子库，再看关联。可视化应显示能改变决定的反例和计数。预测结构、嵌入或模型归因各自有用途和不确定性，不自动成为分子真值。
5. **选择下一证据层。** 描述关联可以形成候选解释；匹配批次/构建背景的独立面板可检验迁移；受控序列改变及适配读出才可能进一步区分机制。依据当前目标选择，不要求同时完成全部层次。

## 一个具体例子：50nt UTR 中的 poly-U 与 AUG

Sample 等2019年的 S5 与 Fig.3 将设计域偏离联系到随机库中稀少的同聚物组成；Fig.1及 S29又涉及上游AUG与设计限制。这提供了两个可检验方向，不能直接解释本项目保存的ridge模型。

本轮先冻结 `max-U-run` 与变量区AUG两项描述诊断，再读取新的分层结果。存储序列采用DNA字母，变量区连续T映射为RNA连续U；ATG映射为该区的AUG motif。出现AUG不等于证明发生翻译起始，也不等于已经定义完整uORF、阅读框或Kozak效应。固定展示分箱只用于本例，不是通用生物阈值。

| 新观察 | 对解释采取什么动作 | 下一步可以是什么 |
| --- | --- | --- |
| 长U段伴随特定残差，且子库内仍有相同方向 | 保留“序列相关失准”的条件假设 | 检查匹配背景或独立测量；解释限于当前模型和面板 |
| 混合面板有关联，子库内减弱或方向相反 | 修改为子库/条件相关解释 | 优先补批次和设计条件，而非只增加重采样 |
| 方向与假设相反或没有可见差异 | 放弃原方向或保留证据不足 | 研究校准/表示等其他解释，不挑新阈值挽救原说法 |
| 关键分层为空或很稀疏 | 显示计数并保留缺口 | 获取合适对象；不把空格画成零效应 |

原文/补充阅读范围和书目见[论文定位](../../ARCHIVE_POINTERS.md#archive-pointer-1f7a18354b3a6a88)。本轮[冻结计划和实际诊断](../../ARCHIVE_POINTERS.md#archive-pointer-a655bc7276d96671)分别保存已知结果、预定新分析和新观察。

## 怎样交给人

篇章随任务调整，读者应能顺着下面的逻辑理解，不必每次填固定栏目：

- **现在怎么选。** 先说当前可采取的决定，说明依赖的用途和条件。
- **为什么。** 用一幅主图或简表给绝对效应、关键对照和会改变选择的反例；用自然语言解释指标、变量与测量的关系。
- **还有哪种解释。** 只展开最重要的一两个，并说明哪项观察会把它们区分开。
- **下一位先做什么。** 给具体输入、用途、首动作、可交付结果与接受/停止依据。摘要可追溯全文和原始工件。

生物图形可用结构文件、序列特征、二维结构或分子渲染辅助解释。选择工具应服务当前问题；预测、示意与实验结构分别标记。先用已有可复现的低成本呈现，工具环境、真实调用、输入/输出身份另有回执。

## 接受依据

读者应能说清：观察到什么、目前更倾向哪项解释、为何仍有替代、什么证据会改变判断，以及接手后的第一步。报告可以没有机制结论，但不能将效用、相关、示意图和机制互相替代。执行成功、方法复核与人的科学认可分别登记。
