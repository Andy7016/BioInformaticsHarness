# 生成结构：几何、精修与误差传播分别验证

版本：`domain-validation-v1.1`，2026-10-18。以FoldingDiff为主要触发实例，方法可按对象迁移。没有结构可实现性或稳健性主张时，不要求运行全部分支；[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)保留。

## 先选目标，再决定需要哪些材料

| 目标/路线 | 输入与首个动作 | 为什么选；合法替代 |
| --- | --- | --- |
| 原始几何是否满足指定约束 | 固定原始结构ID、链/残基/原子映射；明确要查键、碰撞、手性或口袋关系中的哪项。 | 只对声明原子集合与约束下结论；粗粒化研究可保留粗粒化范围。 |
| 骨架能否承载序列/侧链 | 保存原始骨架、候选序列、装配方法、输出与失败。 | 可选过滤，或侧链装配后约束精修；两者改变对象/分母的方式不同。 |
| 表示变换是否正确 | 对固定对象作坐标→表示→坐标往返，核身份和适当不变量。 | 回答表示/转换；不能替代模型误差的传播研究。 |
| 模型误差会否破坏全局结构 | 先定误差来源与扰动设计，再重建并评价。 | 可用有限单角敏感性、联合扰动或局部解析研究；各有不同范围，不强制全部运行。 |
| 预测自洽性或限域解释 | 已报告的逆折叠/回折叠定义、择优规则与分母 | 先解释scTM等代理的范围。真实可折叠性、稳定性或功能需要相应实验或独立证据。 |

## A. 几何与精修：保留对象怎样变化

### 1. 固定原子集合和几何事件

在运行前保存结构版本、链、编号/插入码、缺失残基/原子、altloc、氢/端基及有效mask。比较两个对象时先建立同一原子/残基映射。RMSD需声明是否刚体对齐、对齐和评分的集合；局部/口袋相对几何不能被自由整体对齐消除。

碰撞事件要写明原子类型与半径来源、距离阈值、化学键及邻接排除政策、链间/链内范围和缺原子处理。骨架原子检查回答骨架范围；涉及侧链时，确认侧链原子进入实际检查并记录范围。

FoldingDiff原SI采用非相邻骨架原子距离与Bondi半径，系数0.63。它是本案的来源定义，不是通用全原子阈值；若改查全原子，另定类型、邻接、氢和接触政策并用已知正常/冲突结构核验。

### 2. 在过滤与精修之间选路

- **过滤原始输出：** 冻结过滤规则，保留每个原ID及被删原因。报告原始yield和过滤后质量；不能用好看子集替代全部生成物。
- **装配/约束精修：** 固定每骨架候选序列及数量；装配侧链，保存packed坐标；选择有说明的约束/能量协议，保存relaxed坐标、失败和变化量。先规定允许哪些自由度，哪些相对关系需要保持。
- **不运行：** 缺结构/方法环境时，以作者报告的有限结果作解释，写出需要哪些工件才能改判。

FoldingDiff的实际来源链为ProteinMPNN候选→FASPR→PyRosetta FastRelax→按与原骨架的TM择代表。其它版本化装配/精修程序是合法替代；要重新验证其输入输出与适用对象，不能照搬来源的成功比例。当前指南不安装或运行这些外部依赖。

### 3. 同时保存几何改善和对象保持

逐原始骨架保留全部候选→装配→精修→择代表的谱系。先声明代表是按何分数选出、何时选择；若要估计方法表现，原骨架ID是主要分母，多个候选不是多个独立骨架。

至少把以下集合分开：原始全部`N`、按声明规则保留原折叠`R`、全部精修无碰撞`C`、既保折叠又无碰撞`J`。报告`R/N`、`C/N`、`J/N`和`J/R`及实际缺测，不只给其中最大的一项。若只取得来源聚合数，标明reported arithmetic；没有逐结构结果时不倒造成员身份。

“几何更好但原折叠已改变”可能是有效精修结果，却未必支持原骨架可实现性的原主张。是否允许改变取决于目标：需要保留某拓扑/结合位点时，应在设计中规定适合的映射、结构/局部约束及容许变化理由。TM≥0.5只保留为FoldingDiff的选择，不强制其它任务采用。

## B. 角误差传播：给一个可运行的研究设计

### 1. 选固定结构，先做零扰动检查

按目标长度、结构类别和使用范围选结构ID，记录选择理由及映射。每个对象先用同一转换器完成零扰动重建，量化往返误差，并先区分两种情况：

- **应无损的转换：** 先核ID/链/原子数及单位/方向；再根据数值精度、坐标尺度和正常控制确定可接受的坐标/角差，固定后检查。身份缺失或超过所声明数值容差先修转换，不用TM≥0.5代替精度门槛。
- **固定平均键长等有损表示：** 原生结构到零扰动重建的偏差是表示基线，不强行要求RMSD为零。先核“相同输入经同一转换器重复重建”的数值一致性，再记录相对原生的近似误差和用途可接受范围。扰动增量同时相对零扰动重建比较，原生参考结果另列；这样可区分近似本身与噪声造成的变化。

若正常控制/预期近似不能解释基线误差，或未确定用途可接受范围，停止相应稳健性接受；可以保留描述性响应曲线。不得看完扰动结果才选择较宽容差。

### 2. 根据问题选误差，而非只加任意噪声

| 研究问题 | 设计 | 能支持什么 |
| --- | --- | --- |
| 某角度/位置的局部敏感性 | 固定角类型、端部/中部位置和幅度，一次只改一角，保留正负方向。 | 该结果描述固定结构与尺度下的局部响应；联合模型误差需单独评估。 |
| 实际模型误差是否影响结构 | 从独立或明确开发范围的角误差估计尺度/相关性，记录去噪阶段；按所声明误差模型联合扰动。 | 该误差模型下的传播；单纯独立Gaussian不能自动代表相关模型误差。 |
| 超出训练长度/误差的压力 | 另列更长结构或更大幅度、明确外推标签。 | 压力测试本身；不能据小范围稳定就宣布所有长度稳定。 |

设置包括零点的幅度网格，并用来源误差分布/用途允许误差解释各点；没有误差分布时可做声明的合成压力测试。先按角类型执行以下规则：

1. 对周期为`2π`的二面角（本例φ/ψ/ω），先统一弧度，残差取`e=((predicted-reference+π) mod (2π))-π`。179°到−179°是约+2°，不能记−358°。扰动后也按声明周期wrap，保留周期端点政策。
2. 键角不是任意二面角。本分支默认不扰动键角；若扩展，按其几何物理域、表示定义选择有界分布或显式拒绝重采样，并记录越界比例。不能用二面角wrap或静默clip代替有效性判断。
3. 有匹配的模型误差时，优先保留每个结构/去噪阶段的**整组周期残差向量**，在相容长度、角类型、位置/mask条件下联合重采样，再加到对应参考角并wrap。这保留已观察到的联合关系；随意逐分量独立抽样会改变问题。跨结构/长度迁移要另给映射和依据，缺失时不拼接成完整误差模型。
4. 只有当残差集中于单一可局部展开的角域、可用向量足够且匹配结构时，才可考虑局部中心化/协方差模型；说明角周期、中心和展开方式。跨越周期边界或多模态时，普通算术均值/协方差可能误导，可保留经验联合抽样或仅做声明的压力模型。

记录位置、同时改变数量、残差来源与覆盖、幅度、seed和重复。保持未改的角/键长/参考关系一致；来源误差、独立合成噪声及更大幅度外推分别标记。不机械要求每个项目都拟合复杂噪声。

### 3. 重建、评价、聚合

按`structure × angle/position × amplitude × replicate`保存原输入、扰动、重建、失败和指标。评价至少对应要保护的目标：适当对齐的整体结构、局部位点/几何、碰撞或任务性质；仅保持局部角分布不足以支持整体稳定。

先画每结构/位置响应，再按真实结构单位汇总；同一结构的许多扰动不是许多独立蛋白。区分重复噪声的不确定性与跨结构变异，列覆盖/失败。用计划中的长度/类别分层检查结论是否只来自某一类。

## 科学验收：什么会改变决定

| 观察 | 对应决定 |
| --- | --- |
| 零扰动转换与身份有明确矛盾 | 先拒绝当前转换产物并修复，不解释为生物稳健性结论。 |
| 无碰撞改善主要来自不保原折叠的结构 | 收窄为精修后结构质量；不能将`C/N`写成原骨架可实现率。 |
| 预定相关误差尺度/位置已越过用途允许的结构变化 | 撤回该范围的稳健主张，或限制可用长度/结构/尺度；容许变化须有用途理由。 |
| 所声明范围内、适配的结构和扰动均有结果，且满足预定几何/保持规则 | 支持相应计算可行/敏感性结论；稳定性、真实折叠和功能仍需它们自己的证据。 |
| 只有三结构、两尺度单角示例，或只有聚合数/无原子实现 | 交付限定范围的证据或设计；完整联合稳健性/全原子/历史执行判断保留未知。 |
| 合法替代：过滤、其它精修器、局部解析敏感性或解释路线 | 用该路线的对象和谓词验收；未选路线不生成必做义务。 |

接受前由方法审阅者核原子/几何与扰动前提，研究负责人核结论范围；记录/算术检查只负责自己的局部事件。最小交付为一份设计、坐标/候选谱系、逐单位结果与结论；没有运行时只交设计和缺失材料清单。

## CPU算术入口与可视化

```powershell
python examples/domain-validation/structural_cohort.py --input examples/domain-validation/fixtures/structure-reported-counts.json --output .scratch/domain-validation/structure-counts.json
```

该例读取FoldingDiff来源聚合数，检查集合可相容性和分母；合成逐结构例另测错误/缺失/合法替代。它没有解析原子、计算TM、精修或执行角扰动。真实使用时需要对应工具/规程及回执，[局部例说明](../../../examples/domain-validation/README.md)列出覆盖。

解释时可用PyMOL或同类工具并排展示原始/装配/精修对象，以同一ID/映射着色：被改区域、碰撞原子、保折叠与失败样本；同一视角和标尺便于比较。图可帮助发现映射或局部变化，不能替代几何数值及原子范围。此项按交流需要启用。

## 来源与推导

- **FoldingDiff**：论文补充材料给出两个尺度的单角扰动和结构精修实例。其碰撞定义使用非相邻骨架原子及 Bondi 半径系数 0.63；应用这一定义时应同时保留原子范围和分母，改做全原子分析则另行声明原子类型、邻接与接触规则。[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)
- 本指南在该实例上增加联合误差重采样、零扰动基线、几何改善与原折叠保持的分开判定，以及明确的停止条件；这些是面向新研究的设计步骤。精确页码、图表位置和原归档定位见[机器记录](../../../../machine/document-notes/core/docs/methods/guides/structural-geometry-and-perturbation.md.json)。
