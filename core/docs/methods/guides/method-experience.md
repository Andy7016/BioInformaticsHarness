# 把方法使用经验留在课题中

方法卡帮助研究者选择问题、检查条件和组织行动。课题推进后，把影响下一次选择的观察留在课题目录，后来接手的人就能同时看到方法原意、实际尝试和调整理由。

适合记录的情况包括：适用条件没有对齐、实现或环境阻断、证据尚缺、方法假设受到挑战，以及一次有帮助或未改变决定的尝试。记录深度随观察对后续判断的影响安排。

## 从方法选择开始

1. 读取与当前问题匹配的方法卡或指南，确认本次使用的版本及适用条件。
2. 查看本课题经验索引，阅读同一方法和相近条件下的旧记录及其证据。
3. 决定沿用、补充条件、调整方法、换用其他方法或暂缓，写清理由和会改变选择的条件。
4. 开始实际尝试时，把动作、输入、运行或产物接到当前任务；结果或故障改变决定时补充经验。

卡片只提供导航、具体策略由研究者自行拟定时，分别引用卡片和自拟策略。评价策略效果时先追到实际采用的做法，避免把策略设计中的问题归给卡片。

只读过材料或提出方案时，按阅读或提议保存；实际尝试、完成结果和未执行的设想各自写清。日常工具调用沿用运行记录，经验文件聚焦有意义的观察。

## 在课题里保存

使用[经验模板](../../../examples/research-support/method-experience/experience.template.json)和[索引模板](../../../examples/research-support/method-experience/index.template.json)，在课题根目录建立：

```text
research/
  method-experience/
    index.json
    <method-key>/
      <experience-id>.json
      <another-experience-id>.json
```

每次有意义的观察独立成文件。索引由具名责任人维护，保存可重建的导航；并行执行者各写自己的记录，再由索引责任人汇入。

原经验继续保留。发现记录有误、取得新证据或重访旧问题时，新建记录并注明替代或重访关系，让接手者能追到判断怎样变化。

共享或冻结的方法卡继续作为来源。课题中的条件补充、脚本调整和替代策略保存在本课题，引用相应版本及产物。

## 写清观察与回应

复制模板后，按实际工作填写身份、当前任务、所用方法、研究条件、预期用途、实际尝试、观察、回应、证据和下一动作。模板中的空值表示待填写，记录种类和状态按[机器设计说明](../../../machine/design/method-experience.json)设置。

观察先描述看到了什么，再讨论原因。可选择以下主要类别，并保留同时成立或尚待区分的解释：

- **适用条件不匹配**：当前对象、用途或输入没有满足方法所需条件。
- **实现或环境问题**：依赖、接口、配置或运行条件影响了尝试。
- **证据缺口**：关键测量、来源或比较尚缺，判断停在现有证据范围。
- **假设反例或局限**：指出被挑战的具体命题、它要求的前提和本次证据。
- **有帮助或未改变决定**：说明方法怎样帮助检查，或为何当前选择保持原样。
- **未决**：保留观察、竞争解释和能区分它们的下一证据。

构造反例时说明构造条件和被挑战的命题。构造例展示该条件下的可能性；估计真实课题中的出现频率，还需要相应的观察范围和抽样依据。

回应写明本地作了什么调整、实际结果到哪里，以及谁在什么条件下继续。尚未验证的改法保持待执行，已有的替代解释继续保留。

后续动作逐项连接适用主张、所需证据和重访条件。表级核对、完整复现和因果解释可以有不同前提，分别按实际依赖启动；已有任务或修订路线足够时直接引用。各项未决材料保留自己的作用范围，避免汇成所有后续动作的共同门槛。

应用观察、科学裁定和上游采纳分别记录。填写完整只完成了记录；科学判断引用相应复核，上游采纳引用相应审阅决定。

## 接到当前任务与恢复

经验文件作为既有任务的输出或观察引用，复用 Task、Run、Artifact 和 Decision 的关系。需要改变科学主张或回应路线时，沿[修订与验收指南](revision-responses-and-acceptance.md)处理。

日常经验可以接到当前任务的产物或观察引用。若经验使冻结任务的范围、方案或完成要求需要改变，建立新版本并连接原约定，按[续跑指南](task-continuity.md)继续。

恢复工作时，先读索引，再读相关经验、实际证据和下一动作。确认责任人、当前状态、未决解释及重访条件后，从第一个未完成动作继续。

## 从本地经验到可分享改进

先在课题内积累带证据的观察，再提炼值得复用的候选：它解决什么问题、适用于什么条件、与已有卡片有何关系，以及仍待判断什么。

准备分享时，整理可以公开的来源、证据和许可范围，形成独立候选材料。私有记录与受许可限制的材料继续留在原有范围。

候选经既有 revisor 流程审阅后，可以成为有条件的工作例、适用条件补充或卡片修订。单个课题的经验进入通用指导前，需要审阅其前提、替代解释和可迁移范围。

## 一个假想例子

某课题借助统计单位卡检查重复测量表，又自行提出逐行随机分组的策略。检查发现同一对象进入了两组，团队决定改用按对象分组。

经验分别引用卡片与自拟策略，记录分组现象、证据和选择理由。调整后的比较尚未执行时，下一动作由分析负责人接手，结果保持待定。这个例子用来展示记录方式，观察频率和方法效果需要在实际课题中另行判断。
