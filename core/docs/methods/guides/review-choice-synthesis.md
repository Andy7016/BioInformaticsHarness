# 从已读文献写出方法取舍

这一步用在综述初稿已有主线、方法比较却仍像名称清单的时候。它接在[覆盖与收束](review-coverage-and-closure.md)的范围评议中，帮助把读过的条件写成读者可以使用的判断。

## 从读者要作的决定开始

先取一段核心论述，问读者读完后能决定什么：现有数据能否回答问题，为什么考虑这条路线，换一种条件后应怎样处理。回到支撑该段的来源，优先看方法比较、输入要求、局限与讨论。

改写前保存初稿，并说明正在处理哪一项问题、哪一版交付、什么使用范围和哪条回应路线。同一句话在“解释一个有界实例”和“比较主要方法路线”下承担的义务不同。旧版已达到的范围继续保留，新增比较另作判断。

| 阅读时问什么 | 在综述中接上什么关系 |
|---|---|
| 作者想估计、预测、重建或解释什么 | 生物学问题与方法目标，目标变化时需要另作比较 |
| 哪些信息可用，哪些缺失、带偏差或来自别的总体 | 数据条件与路线选择，补充信息的价值 |
| 方法怎样表达对象关系，哪些假设使结果可解释 | 表示、推断与生物学含义 |
| 什么证据说明做得好，是否对应使用目的 | 评价对象、允许的主张与下一步选择 |

这些问题供挑选合适的角度。专题决定哪些角度重要；一份狭窄综述可以直接解释其余角度为何不影响当前决定。用条件和关系命名分支，方法名称作为查找入口。

## 先变条件，再检查目标是否改变

第一遍保持研究目标不变，只改变一个重要条件，例如可用标签、观测单位、测量噪声或部署范围。将当前路线与合理替代并排，说明原路线还能回答什么，需要补什么，以及哪项依据使替代更合适。这个比较可以帮助找出尚未写明的假设。

第二遍重新看目标。若从估计效应大小改成判断方向，从描述逐基因变化改成解释通路或模块，方法的输入、输出和评价对象也可能改变。先定义新目标，再选路线和评价；旧目标下的高精度或好表现仍按原用途解释。[输入与目标工作例](../../../examples/research-support/preparation/choice-synthesis-example/README.md)并排演示这两类变化。

若只是同一前提下的实现变体，可以留在同一分支；若信息资格、推断目标或使用含义不同，应在地图中显出关系。已有来源不足时，再判断是否值得补一份基础比较、教程或原始研究。每次新增阅读都应有它要改变的判断。

## 将笔记改写成有依据的论证

可以先用五句话整理一项选择，再写成自然段落：

1. 本段回答什么问题，涉及什么对象或目标量。
2. 在什么数据和假设下，这条路线能提供什么结果。
3. 来源哪一处支持该关系，原作者实际比较或报告了什么。
4. 条件或目标改变时，有什么合理替代，它保留或失去什么。
5. 当前据此怎样选择，哪种新证据会使选择改变。

分开表达原作者的报告、综述作出的综合，以及尚待验证的建议。原文只描述一种方法时，可以据此提出有理由的下一步比较；性能排序需要相应的比较证据。总体、版本、单位和主张强度在改写后继续保留。一个来源可以支持多个关系，同一关系也可由不同来源或等价证据支撑。

复合问题按能独立判断的关系展开。例如“差异表达、基因集与调控网络”至少涉及不同的推断对象。差异表达写得充分时，仍逐项查看另外两部分的来源和论证。[单细胞旧例](../../../examples/research-support/preparation/choice-synthesis-example/mast-resynthesis.md)展示怎样保留已有成绩，并补回一项已读未写的关系。

## 按缺口选择路线和产物

同一缺口可以有合理替代。先选择本轮要回答的部分，再明确过程、输入用途、下一动作、产物和验收：

| 路线与适用条件 | 过程与输入用途 | 下一动作和实际产物 | 验收看什么 |
|---|---|---|---|
| 解释或重综合：关系已读，正文尚缺条件或含义 | 对照原段落和已读位置；来源用于解释已报告的方法与条件 | 改写段落或一页比较表，连接原问题地图；交付可阅读的新文本 | 来源支持新论证，读者能说出条件、选择与评价；其余未回答关系仍明确 |
| 定向补读：关键比较只有提名、原件缺失或现有证据不足 | 先命名待补关系，再选合格原件、作者稿或等价证据；实际读到的内容用于该比较 | 交付阅读位置及它支持的论证，更新地图；取不到时交付缺口与后续决定 | 具体版本的已读材料支持所述关系，新增下载和引用分别记录 |
| 科学验证：新数据或结果才能判别候选解释 | 先确定比较对象、输入用途、独立单位、参照和评价，再按研究授权执行 | 先交付验证设计；执行后另交付运行、结果及主张更新 | 判断实际结果能回答哪项科学问题；尚在计划中的比较保留待执行状态 |

解释路线可以独立完成。若原请求还包括方法性能比较或机制验证，解释完成后继续保留这些问题的处理决定。未选的替代路线保留理由，后续新证据或用途变化时再选择。重要研究方向或投入变化，带着证据、选项和建议向人讨论。具体交接沿用[回应路线与验收](revision-responses-and-acceptance.md)及[具体义务与交接](guidance-calibration-and-handoff.md)。

## 固定交付后，主动重读相关原文

初稿或首交已固定，但读者仍难判断怎样使用，或补查持续围绕少数分支时，可以启动一轮重读。先确认接收的是哪一版主文、来源账本和依赖包；缺文件先说明缺口，沿已有[封存与交付接口](plan-seal-and-first-execution.md)或等效不可变版本保存旧包。接收确认说明文件齐备和版本一致，科学内容另作评议。封存沿用原访问边界，隐藏参照及评图仍按任务授权处理。

交付确认后，鼓励受派研究者主动完整重读本次实际依赖、与当前决定相关的原文，包括正文、方法、表图及图注。只核对已知评阅位置时，记录为选段阅读。相关补充材料逐项说明是否取得、读到哪里、缺失会影响哪句判断。按价值与预算排序；时间不足、原件不可得或尚未完整读完时，保留实际范围和恢复条件。引用文献按当前问题选读，无需递归读完整个书目。

把重读笔记和新稿放在旧包以外的新版本中。允许重读后没有新增遗漏，原本充分的论证继续保留。取回全文、抽取文本和填写阅读字段分别是获取、处理与记录动作；实际阅读范围由研究者如实说明，并接受内容复核。

## 按当前决定切换视角，再诊断缺口

视角从材料和用途建立。先从作者明确写出的目标、对象、操作和证据恢复原研究；当受众要据此选择或使用时，再问其实际需要什么；转入当前生信任务时，核对对象、信息、部署范围和评价怎样改变。作者、受众与当前任务是定位入口，相关视角随具体不匹配展开。例如论证涉及测量生成、剂量与毒性、结构或部署用途时，先说明它为什么影响当前判断，再回到相应来源。学科、作者身份或一个主题词本身不足以确定立场或追加义务。提示唤回的既有知识可以帮助提出问题，精确科学主张仍回到合格原文。

按触发选择下面的问题，无需每篇遍历全部角度：

| 共性问题 | 重读时接通的关系 | 可能改变的下一步 |
|---|---|---|
| 用途决定评价 | 作者解决什么、读者准备做什么，输出和评价是否对应 | 换用途后重选目标、解释或评价 |
| 辨认信息用途与对象 | 输入、先验、训练、选择、测试、参照各做什么；单体、窗口、蛋白对、复合物分别是什么 | 先纠正信息流和对象，再选择方法 |
| 比较条件 | 同一目标下，样本、表示、版本、预算、选优和合理替代怎样不同 | 条件未匹配时保留系统比较，单项增益继续待证 |
| 诊断缺口并选回应 | 原文已有未写、读过未理解、缺比较、缺原件，还是缺新的经验结果 | 优先重读与重综合，再按所缺证据选择补读、获取、验证或收窄 |

输入、标签和指标分别正确，读者仍难判断怎样使用时，沿[对象到用途的论证](biological-explanation-and-handoff.md#从对象到用途接通关系)核对观测单位、特征形成、标签证据与候选动作之间的理由。先把来源支持的关系写进正文，再决定是否需要新材料或新验证；[Yeast 工作例](../../../examples/research-support/preparation/choice-synthesis-example/biological-argument/README.md)展示完整的一条链。

复查时分别寻找遗漏、缺分析和注意分配偏窄，并记录反证。遗漏要指出原文中什么关系尚未进入旧稿；缺分析要说明哪项必要比较、解释或跨来源综合尚未做；注意偏窄要用旧文与用途说明，哪些已充分的细节反复展开，而会改变选择的条件未获处理。旧稿已有清楚区分和合理范围时，可以保留它。这里的“过度注意”讨论论证的注意分配；诊断统计学习中的过拟合需要相应数据与统计设计。篇幅、旧分数或相同方法名本身都不足以作这两类诊断。

沿“原文位置—旧文关系—实际影响—回应路线—新正文或保留缺口”完成修订，接回原地图和[回应路线](revision-responses-and-acceptance.md)。新增结果才可判别的问题，先交验证设计和资源判断；解释路线交付新的连贯论证。参见[AF2Complex 完整重读与重综合例](../../../examples/research-support/preparation/choice-synthesis-example/rereading/README.md)，其中原有对象区分被保留，已知预算遗漏进入新正文，未做的匹配比较继续开放。

## 用修订前后检查含义是否改变

把旧段落与新段落并排，指出新增的条件、替代、评价联系或撤回的判断；若旧文已经有限定，就准确说明这次补充了什么。暂时遮住方法名和来源名，检查读者还能否判断对象、条件、可选路线和评价理由。

例如，“方法甲、乙各有假设，研究者应选择合适方法并检验稳健性”，遮去名称后仍只有建议，没有选择依据；即使已经填上过程、输入、下一动作、产物与验收五栏，也要继续追问每栏的科学内容是否成立。方法名、引用和字段完整分别提供导航与交接信息，实际关系还须回到原文判断。

最后把处理结果接回原地图：已有分支补条件，新关系按用途加入，暂缓或排除的关系保留理由。简短综述可以只交付一段论证或一页表格，沿用已有来源账本。记录应足够支持接手与判断，形式随任务选择。
