# 补什么数据，拿到数据后怎样更新模型

版本 `label-update-guidance-v1`，2026-10-19。来源：[Optimus I02/I04](../../ARCHIVE_POINTERS.md#archive-pointer-f3ff4f03baa8b83a)。这是失准、补标签、表示敏感性和多域用途的条件工作例；不规定每项研究采用ridge、两个表示或固定预算。

## 何时进入这条路线

模型进入目标域后失准，补少量目标标签带来很大收益，或者不同表示对校准/重拟合的排序不同时，先拆成两个决定：**获取哪一类标签；获取后用什么更新。** 没有补数据或更新选择的任务无需套用。

## 拿到材料后的顺序

### 1. 先确定用途及公平的比较对象

写清未来对象、主要评价域、测量含义和允许的源域损失。列现有模型、可获取标签的来源、成本和资格。用共同基准与等量/等成本预算比较标签来源；若费用或可用输入不同，明确比较的是哪个实际策略。

最少输入是：单位级标签与预测、各来源/阶段集合、开发与保护评价边界、表示与更新定义、购买/选择身份、源/目标用途。缺历史选择信息时保持其归属未知；可以比较现有保存输出，不必重建完整作者模型。

### 2. 先看绝对基准，再读相对提升

同时报告目标域的绝对误差、平均有符号偏差，以及适用的简单/常数参照。大的相对收益可能同时包含新增信息与失准基准的修复。简单参照也要说明其来源与可见标签，不能从保护评价标签估计后冒充可部署基线。

源域结果用于判断迁移代价，不能因目标域胜出就忽略；如果当前用途只要求目标域，可明确接受这个范围。需要同时服务两个域时，先写权重或可接受损失，再作采用决定。

### 3. 保持一个因素可比较，再选择更新

| 要回答的问题 | 适合的比较 | 能据此说到哪里 |
| --- | --- | --- |
| 哪类新增标签更值得获取？ | 同表示、同基准、同更新、匹配预算下，来源A与B | 当前策略和面板下的获取效用；不是所有域都应购买同类标签 |
| 获取标签后怎样更新？ | 同表示、同新增标签集合下，简单校准与重拟合 | 当前用途下的更新取舍；标签有用不自动决定重拟合更好 |
| 效果是否依赖表示？ | 在各表示内分别完成上述比较，再比较排序与幅度 | 哪层判断稳定，哪层需要条件化；不能把同步变化全归给某个特征 |
| 是否值得承担源域损失？ | 两域的绝对误差和用途权重/容许损失 | 当前采用条件；没有用途判据时保留待决 |

截距校准只是一个低成本替代：偏移、缩放、排序或局部关系失配时所需方法不同。可以使用已有合适校准法或保持固定学习器的有限策略比较；无须为完成指南尝试全部更新方法。

### 4. 把操作阈值与连续结果同时交付

对当前案例，来源收益可以写为同更新下 `MSE_random − MSE_design`；更新收益可以写为同设计标签下 `MSE_offset − MSE_refit`。正负号与哪个方案更好要解释清楚。

若用“校准恢复了多少重拟合收益”，明确其事件为 `(MSE_base − MSE_offset) / (MSE_base − MSE_refit)`，并先判断分母和用途是否允许这种解释。分母非正或接近零时，不用一个不稳定比例作决定。沿用旧阈值时保留原约定，展示连续效应、绝对误差和适用的不确定性；阈值两侧不作为生物机制分界。

同一评价面板被多个购买seed重复使用，不能把“记录数×seed数”作为独立生物样本数。重采样服从独立单位/配对和估计对象；没有适配独立性时给描述结果与逐seed取舍即可。

### 5. 留一个会改变结论的出口

选出的超参数在预定网格边缘时，先记录可能的开发范围限制，不能直接判训练错误。若当前问题仅是固定学习器比较，可以接受有限结论；要扩大为普遍最优更新或机制结论时，再冻结合理开发扩展，继续保护评价集。

表示间排序相反时，将推荐写成条件判断；数据没有支持某个生物原因时，转到[解释与人读交接](biological-explanation-and-handoff.md)，提出能够区分替代解释的下一证据。

工作例交付应让读者分别回答“补哪类标签”“采用哪种更新”，并知道哪些比较依赖当前面板、表示与用途。不得将作者的相关系数平方与本研究 predictive R²混作同一指标排序。当前数值、程序与后补诊断分别绑定，不改原判据或原研究。
