# 序列表示、目标与长输入

## 适用条件

用于 DNA、RNA 或蛋白序列的 tokenizer、k-mer/BPE、mask/MLM、长序列分窗、双臂输入，以及把一维表示外拼成二维张量的任务。若输入不是序列，或没有窗口/二维步骤，相应小节记 `not-applicable`。若序列坐标还要映射到 assembly、strand、TSS、track 或输出 bin，另启用[坐标与参考系变换卡](coordinate-transforms.md)；本卡不代替联合坐标契约。

## 应记录

- `DataSnapshot`：原始序列 ID、来源与版本、规范化（如 T/U）、字母表、tokenizer/词表 revision；保存 token 到原始 nt/残基区间的映射，特殊 token 单列。
- `SplitPlan`：词表、标准化、相似性或家族规则用了哪些 partition；拟合范围与实际保留的序列/碱基数。
- `MethodCard`：mask 采样、目标、loss 权重、无效位置处理、有效 token/nt 长度；不要只写“按 token 训练”。只有当研究目标确实要求隐藏位置不可从允许输入中直接得到、且该信息通路会构成不允许的答案通路时，才把可预测性记为目标泄漏；天然序列规律本身不是自动失败。
- 长输入：每窗起止坐标、有效长度、stride/重叠、尾段、padding/mask、窗口聚合权重及无法保留的跨窗关系。
- 一维到二维：两轴含义和顺序、是否去掉 CLS/EOS、padding 覆盖、对称性、pair mask、形状与显存边界；双臂输入另记每臂区间和类型 ID。
- `Run`：解析后的实际配置、截断/分块结果和产物覆盖；不要把默认配置当实际配置。

## 可判断的检查

1. 用短序列回映射 token 区间；按目标定义核对哪些特殊 token 被评分或排除（MLM 例明确核对 CLS/EOS），双臂分别保留坐标和身份，避免混淆，样本 ID 能回到原始快照。
2. 若目标要求隐藏且答案通路被研究规格禁止，检查 masked 位置是否仍可由不应可见的输入唯一推出；改变碱基位移或 mask 位置后，记录目标泄漏和表示稳定性。若任务允许利用天然上下文预测，则记录为任务性质或可预测性背景，不判为泄漏。
3. 对账 token 预算与 nt/残基预算。逐窗覆盖应包含尾段；等窗权重和按有效碱基加权必须是可比较的明确选择。
4. 对小矩阵检查一维到二维的行列坐标、padding/mask；对最终无向关系按约定检查对称性，不强求所有原始分数对称。若形状不符或运行超出预算，记录实际差异与处置。
5. 对配对输入检查特殊 token、类型 ID 和每臂截断是否真的进入模型；需求未使用类型 ID 时也记录理由。

## 替代与不适用

字符、k-mer、BPE、重叠或非重叠窗口都可用，但必须说明坐标映射、覆盖和 loss 计权。按 token 或按原始碱基计权也不预设答案。没有二维操作时跳过二维检查；没有长序列时不要求虚构窗口。相同 token 数不能自动称为相同生物序列覆盖。

## 小型验收例

- 正常：12 nt 字符 token，mask 的 token 区间可回到原序列，CLS/EOS 不计 loss；逐样本 ID 和目标长度对得上，标记 pass。
- 失败：研究规格要求隐藏目标碱基，且禁止把同一碱基从重叠 token 直接暴露；未 mask 的邻 token 却仍唯一包含答案。即使 loss 正常，也按该禁止通路判目标泄漏 fail。允许的生物学上下文预测不属于此例。
- 正常：长度 19 的序列按 8、stride 6 分窗，窗口是半开区间 [0,8)、[6,14)、[12,19)，末窗含 7 nt；覆盖量按坐标并集统计，表征聚合对重叠区的权重另行明确。
- 失败：L×L 张量把 padding 当有效 pair，或两轴坐标错位；短矩阵的对称/无效 mask 检查应拒绝结果。

## 来源与推导

- **DNABERT-2**：长序列和双臂输入需要把窗口边界、输入身份与输出覆盖一起记录。
- **RNA-FM**：分窗输出连接到二维结构时，应保留一维序列坐标与 pair matrix 两轴之间的映射。
- **RNAErnie**：按原坐标并集计算窗口覆盖，并单独说明重叠区如何计入表征；末端短窗仍是有效输入的一部分。
- [校准后的关系契约](../../design/13-calibrated-relations-and-checks.md)：D24 说明按具体研究条件定义关系和覆盖义务。
