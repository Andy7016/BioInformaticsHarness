# 基准开发、教师监督与公平比较

## 适用条件

用于自适应负例/难例基准、教师标签或蒸馏、预训练与 from-scratch 对照、跨模型基线，以及任何会在看过结果后修改数据或评价口径的研究。若要核对选择事件与实际 partition 角色的关系，补充[校准后的关系契约](../../design/13-calibrated-relations-and-checks.md)；本卡的科学判断仍不由声明式检查器替代。

## 应记录

- `ResearchQuestion`/`ComparisonSpec`：目标总体、单位、泛化轴、预算和比较目的；区分“模型拟合困难样本”和“研究者按模型结果改造测试集”。
- `DataSnapshot`：来源版本、实体 ID、阶段×实体×来源版本暴露矩阵；教师训练截止、标签生成日期、开发/测试可见性。
- `SplitPlan`：训练/验证/候选池/校准集/最终封存集；负例生成机制、匹配背景属性、每轮增删、当轮可见 partition 和封存时点。
- 教师与学生：教师模型/权重/输入指纹、质量阈值与采样权重；学生有效 loss 分母、mask、混合比例；teacher-derived、实验或独立参考标签分别标注。权重期望/实际消费和组件角色另按[执行证据卡](execution-evidence.md)记录。
- 基线与运行：架构/参数、初始化状态、数据与搜索预算、seed、失败/重试及实际输出；缺权重是否允许 scratch 要有 `Decision`。
- 比较：相同任务单位、后处理、指标方向、覆盖和有效分母；把一致性、实验准确率、外部泛化和完整 workflow 分开。

## 可判断的检查

1. 从每轮样本 ID 重建曝光矩阵；最终测试/封存集一旦被用于选阈值或添加难例，该比较标为污染或改为开发结果。只声明“test”而没有选择事件历史时，保留 `unknown`；ID互斥本身不能证明未参与选模。
2. 把教师生成标签连接到 `Claim`。教师—学生一致性可以成立，但不升级为独立真值；实验参考和 teacher-derived 结果分列。
3. 对齐基线的数据、后处理、训练/搜索预算和初始化；不同架构可以比较，但差值归因必须保留限制，不能把小模型对照自动叫公平因果基线。
4. 从逐单位结果核对正类方向、NaN/全零跳过、任务计数和有效分母；汇总分数不能遮住被删样本。
5. 对 checkpoint 消费验收来源、实际载入名称和形状；缺文件后继续随机初始化而标签仍写“预训练”应判失败。参数名或文件 hash 只能证明身份层证据，实际加载/作用算子按[执行证据卡](execution-evidence.md)区分。
6. 将结构、序列或效率比较的代理真值与独立参考一并展示；不把教师一致性或演示图当生物机制证据。

## 替代与不适用

自适应基准、外部封存测试、教师伪标签和实验标签都可用，关键是声明用途和依赖。公平比较不必强制同一架构或同一参数量，但必须记录预算、数据、初始化和覆盖。没有教师或基准迭代时跳过相应记录；不要为了填表虚构历史封存过程。

## 小型验收例

- 正常：校准模型只看 train/dev，难例在开发轮加入，最终封存集从未用于阈值或样本选择；外部结果单列，标记 `pass`。
- 失败：先看 test 分数，再按错题增添负例并继续报告同一 test 成绩；曝光矩阵应标记 test contamination。
- 正常：教师一致性、实验结构准确率和独立参考各有分母与标签；结论只写到对应证据范围。
- 失败：预训练 encoder 文件缺失却从随机初始化继续，并将结果放进“预训练收益”表；应暂停或建立新的 scratch 比较。
- 正常：四层 from-scratch 基线报告参数、数据和预算差异；可比较实际系统，但不能把所有差值归因于预训练。
