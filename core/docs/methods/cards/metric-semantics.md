# 指标语义与数学事件

## 适用条件

当指标的数学定义、真值类型、单位、有效分母、区间表达或聚合方式可能改变研究结论时启用。适用于单细胞表达分数、分类/回归、结构指标、相关系数、分位数区间、均值比例区间及跨任务宏/微平均。只有简单展示原始值且这些语义已由上游契约完整绑定时，才可记 `not-applicable`。

本卡不要求所有任务采用同一指标、同一区间或同一方向；它要求同名数字不能掩盖不同的数学事件。任意论文公式不自动成为全局 Harness 规则。

## 最少必要材料

- `metric_event`：指标名称、数学表达式或可定位实现、输入单位、输出单位、方向（越大/越小/目标值）、真值/代理真值类型和比较对象。
- `denominator`：评价单位、有效样本/任务/结构集合、过滤与缺失规则、每项的 `n`；区分“没有结果”“失败”“有理由排除”和真实零值。
- `aggregation`：逐单位结果、宏/微/加权聚合、权重来源、归一化、区间/分位数定义和估计方法。跨任务聚合须保留任务 ID 与输入贡献。
- `implementation`：计算实现、版本/commit、参数、数值精度和结果文件或可复算输入的身份。实现版本与数学事件不一致时要显式记录。
- `claim_binding`：该指标支持哪个主张、依赖哪一种真值，不能把教师一致性、预测—预测一致性、实验准确性和外部泛化混写。

当分母来自多阶段筛选或择优时，联用[逐阶段选择](stage-selection.md)绑定候选、入选、送测/有效项及单位变化；当真值/代理依赖先验、教师或评价器时，联用[信息用途](information-use.md)标明影响路径。若选择后估计涉及重复、嵌套或相关观测，另参阅[统计单位与选择后估计](../guides/statistical-units-and-selection.md)确定估计对象和区间单位。`research-flow-v1`能核声明集合与阶段，不代替本卡的数学定义或领域计分插件。

## 可判断的检查

1. 先按数学事件重算一个最小逐单位结果，再检查方向、单位、过滤和分母；只看汇总表不能证明分母一致。
2. 区分宏/微/加权聚合。若任务 A 有 10/10、任务 B 有 0/1，宏平均为 0.5，按样本计的微平均为 10/11；两者都可合法，但不能使用同一个未标注的“平均准确率”。
3. 区分区间事件。对手工例 `[1,1,1,1,9]`，指定分位数规则得到的分位区间与均值加减 5% 的比例区间表达的是不同事件；保留定义、规则和单位，不能因图形相似而互换。该例是语义验收例，不是论文结果复现。
4. 已知实现与声明数学事件不一致，或把有效分母改变后仍沿用原主张，判 `fail`；缺实现版本、逐单位结果或过滤原因，判 `unknown`。数值恰好相同不消除语义差异。
5. 当前 `research-relations-v1` 的 `aggregation` 只核对提供的标量线性项、系数和贡献账本；它不解析任意 metric callable、图像或科学真值。其 `pass` 只代表给定记录通过，不代表指标实现正确。

## 合法替代与不适用

均值、分位数、bootstrap 区间、任务宏平均、样本微平均和其他加权方案都可用，前提是与研究问题和真值类型绑定。不同任务可有不同单位和指标，但跨任务报告须保留任务边界；无法取得逐单位结果时可以报告摘要，须把可复核范围标为 `unknown`。没有比较或指标聚合时跳过，不要求为了填表制造公式。

## 小型验收例

- 正常：保存每个 cell 的预测、真值、有效状态和指标实现 revision；报告 median/quantile 时同时写分位数规则，报告均值比例区间时另列公式。
- 失败：将分位区间改名为“均值 ± 5%”，或把任务 A/B 的微平均写成宏平均；最小数据例应暴露名称、分母或区间事件的差异。
- 正常：失败输入有明确 `failed` 状态，带理由排除项不进入有效分母且仍在账本中；coverage 与 accounting 分开。
- 失败：缺失预测的处理与已声明计分政策矛盾，或把未观测结果静默当作真实零值；用 teacher-derived 标签生成的高一致性直接声称实验准确率也应被拒绝。预先声明“失败计零、按全部任务作分母”的失败惩罚可以合法，但须保留失败状态、分母和政策，不能冒充观测值。
