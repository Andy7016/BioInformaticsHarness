# 修订指导交接：让选定路线可以继续执行

修订指导交接适用于评审意见、项目复核和跨团队任务。它把一个具体请求连接到指导来源、负责人、输入用途、任务、产物和验收结果。与[修订记录指南](revision-contract.md)配合时，前者帮助决定谁根据哪些材料做什么，后者帮助把回应连到最终主张。

## 从请求到当前工作

1. **定位请求。** 保留原文和具体位置。把同一句中的独立要求拆开，避免只交付其中容易完成的一项。
2. **确定当前路线。** 选择解释、重新分析、验证、收窄主张、保留限制或回应。写清路线负责人、选择理由和仍未解决的问题。
3. **分清当前工作与历史描述。** 作者报告、历史运行和当前团队的工作分别记录。历史路线说明背景，不能替当前任务补上缺少的运行或结果。
4. **为任务写清用途。** 列明每项输入用来定义问题、确定方法、执行分析还是评价结果；标注负责人和预期产物。将每个产物连接到其来源或任务。
5. **说明怎样验收。** 记录检查对象、可观察的条件、负责人和回执。把登记了检查、实际执行了检查、结果支持了科学主张作为不同状态。

当前路线所需的材料决定交接是否可用。解释请求可以用原文和清楚的方法定义回答；重分析需要数据与方法；验证需要适用的参照和明确的读出。未选择路线的材料缺口不必阻断当前路线，但仍可作为后续问题保留。

## 保留缺口和结果边界

必要指导来源缺失、版本不清、任务输入未说明或产物未提供时，把受影响的部分标记为未知，并写明补充什么材料可以解决。对当前路线用到的关键指导或具体实现，版本信息应足以让后续接手者找到相应材料。其他来源版本暂时不明时，把它作为待确认事项记录。

已完成任务要指向实际产物；计划、受阻或未知的工作保持对应状态。科学判断需有独立结果和解释。检查清单或交接记录可以表明流程关系完整，但不能替代数据质量、分析适用性或生物学结论的审阅。

回执应与它所支持的检查相对应。缺少回执时，结果仍待确认；已声明的失败结果应原样保留，并说明它影响哪项主张。范围只覆盖一条选定路线时，说明原请求还有哪些部分未评价。

## 选择适用的工作量

- 术语、流程或测量解释：引用定义和请求位置，写出解释范围。
- 数值复核：说明数据、单位、指标和分母，并链接可复核的计算产物。
- 新实验或模型验证：先说明独立参照与会改变结论的读出，再安排执行。
- 证据不足：给出最小的补证路径，或将主张限于现有材料支持的范围。
