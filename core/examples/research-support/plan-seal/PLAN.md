# Example first plan

## Question

Can the declared reader consume one saved result and reproduce its recorded
identity?

## Planned check

1. Freeze the input file list and the expected output fields.
2. Run the producer once and save its output.
3. Open that output with the intended reader and compare the declared fields.
4. Record errors and stop if required identities are missing or conflict.

This example demonstrates the seal interface only. It contains no scientific
result or method approval.
