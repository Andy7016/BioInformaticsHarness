# 研究指导闭环记录

本目录把 D53 的文献和证据综合接到一次面向人的讨论，并在实际选择研究方向后继续到数据、首计划、执行评价和证据修订。先读[研究指导闭环指南](../../../docs/methods/guides/research-guidance-cycle.md)，再将机器模板复制到当前研究的记录目录。

## 从准备记录开始

沿用[D53准备示例与模板](../preparation/README.md)生成来源账本与证据图。把实际阅读的覆盖范围、共识与适用条件、未解分歧、方法候选和候选问题整理成一份面向人的说明。准备讨论时，复制[人读讨论提纲](HUMAN-DISCUSSION.template.md)，按本轮问题删改内容；机器周期记录和讨论记录的字段见 `cycle.template.json` 与 `discussion.template.json`。

## 留下真实选择

说明对象、测量、用途和方法关系图，挑出影响路线的一两个争论与解释，给出可行选项、推荐理由、成本、替代和改判条件。讨论中记录人的实际意见及来源；若还没有讨论，把阶段保持为待讨论。 准备完成时，材料进入可讨论状态；方向选择引用实际讨论和有效选项。

同一轮可有不同出口：

- 交付有明确覆盖范围的独立综述；
- 继续定向阅读或等待关键材料；
- 明确转入一项研究；
- 保持现状、暂缓或停止，并写明恢复条件。

人没有提出新的方向决定，且当前工作仍在原有授权范围内时，沿[D51任务连续性](../../../docs/methods/guides/task-continuity.md)推进常规事项。需要人确定目标、用途、优先级、关键测量或预算边界时，以真实讨论记录支持方向选择。

## 选定研究后的接续

当人选定新研究后，在 D53 study bridge 中引用所选问题、发现和方法，并记录数据来源、版本、许可、实体和测量语义、覆盖分母、信息用途、预算、责任人及资源缺口。将 bridge 连接到新的 D51 `study_id` / `iteration_id`、当前工作根和首计划版本。其他平台如提供等效任务、决策与执行证据，使用相应适配或人工复核。首次审计会影响样本纳入、清洗或划分时，先按[计划封存与首次执行](../../../docs/methods/guides/plan-seal-and-first-execution.md)封存。

研究周期、来源账本、证据图、讨论记录和首计划各自保留版本与路径，引用时注明对应记录，不要求编号相同。仅推进阶段且研究范围及 D51 任务绑定未变时，沿用原讨论记录和首计划；执行评价与证据修订可以引用同一份实际运行。研究范围、目标或 `iteration_id` 变化时，重新核查 D51 当前任务绑定；旧运行留作历史材料，不作为新绑定下的当前运行。

执行与评价记录实际消费的输入和产物，再把观察、分母和结果连回本轮预定判断。结果驱动的范围或方法调整新建版本；原计划与保护评价集仍按其原始定义保留。资源不满足当前目标时，按[D52资源缺口闭环](../../../docs/methods/guides/resource-gap-loop.md)补充、换源、收窄、暂缓或停止。

历史综述进入新课题时，引用它的版本和覆盖时间；当前问题所需证据若已变化，附一份可读更新记录，说明新增或重查内容如何影响选择。[D53 Splice资源准备回看例](../preparation/splice-reading.example.json)提供一份已接受准备记录，后续可按本目录简报模板说明资源路线并收集人的真实方向选择。

[Splice人读讨论简报](SPLICE-DISCUSSION.md)以已知对象和实体关系缺口为例，展示如何向人说明保留现有资源或补充来源的路线；实际研究方向仍待真实讨论决定。

## 结构检查

[机器设计](../../../machine/design/research-guidance-cycle.json)说明阶段、引用关系和结构检查边界。周期检查器说明当前交接记录与阶段前置条件是否齐备；研究结论按对应研究评价流程判断。

## 选择综述出口

方向记录可以选择研究、综述交付、继续阅读、保持现状、暂缓或停止。只有开始研究的方向需要把具体问题与方法接到数据和首计划；其余选择按本轮目的结束或继续。机器记录中的具体字段和原生接口范围见[契约](../../../machine/design/research-guidance-cycle.json)。
