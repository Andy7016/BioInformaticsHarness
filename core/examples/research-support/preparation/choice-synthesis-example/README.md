# 工作例：输入与目标怎样改变方法取舍

设想一份关于遗传证据与因果问题的综述，初稿写道：

> 孟德尔随机化可以借助遗传变异研究因果关系。常用方法包括两阶段估计，也可以开展两样本分析。后续应扩大样本并检验稳健性。

这段话列出了方法，读者仍需自行判断能走哪条路线。先把问题收敛为：对同一个暴露 A 与结局 B，现有材料支持怎样的估计，需要补什么信息？

## 先确定来源报告了什么

本例使用 Davey Smith 与 Hemani 的二〇一四年综述。下面各项按原文小节和图表定位；其列举的研究属于综述作者的报告。[原综述全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4170722/)。

| 原文位置 | 本例采用的报告 |
|---|---|
| “Basic principles”、Figure 1、Box 1 | 工具需与暴露相关，只经暴露影响结局，并与相关混杂因素独立；后两项需要额外依据。Box 1 用两阶段最小二乘解释工具变量估计 |
| “Use of multiple variants”前几段、Table 2 | 扩大样本或增加解释暴露差异的工具可改善精度；多效性及连锁不平衡另有风险与检查思路 |
| “Two-sample Mendelian randomization”两段 | 暴露与结局可在独立资料中测量；发现工具与估计使用同一数据时，分样本可缓解赢家诅咒造成的偏差 |
| “Bidirectional and network Mendelian randomization”前三段 | 判断方向需要两侧的有效工具及它们之间的关系；工具的主要生物作用不清楚时，双向分析可能误导 |

下面的选择表和改写段落由 Harness 将这些分散关系组织成研究准备建议。输入定义是否相容、选择哪种具体估计量及怎样诊断，还要按目标和相应原始方法核对。

## 固定目标，改变可用输入

先保持“估计 A 对 B 的效应”不变。

| 当前材料 | 可考虑的路线 | 选择与评价要接上的条件 |
|---|---|---|
| 同一研究有个体层遗传、暴露和结局资料 | 在相应模型下考虑个体层工具变量估计，Box 1 给出两阶段最小二乘例子 | 说明目标效应、工具有效性与模型条件；评价估计的不确定性并检查识别依据 |
| 暴露与结局在独立研究中测量 | 按两样本设计组织资料，再选匹配的估计方法 | 先核对输入是否支持同一目标效应；发现、估计及研究间差异怎样影响偏差与精度 |
| 有可信证据显示工具绕过暴露作用于结局 | 重新审视工具、设计或因果问题 | 增大样本针对精度；绕行路径需要识别证据及相应处理 |

第一行与第二行的区别来自资料安排，目标仍然相同；表中核对输入和评价的动作是本例的组织建议。原综述描述这些设计的用途与风险，本例据此说明准备次序。

## 目标改变时，重选路线与评价

现在把问题改为“是 A 影响 B，还是 B 影响 A”。原来单向效应的精度成为部分信息，新任务还需要两侧工具的有效性、主要生物作用和两侧关联。按原综述的双向小节，工具之间缺少相应独立关系或主要作用混淆时，应先补识别依据、改选工具或保留方向未定。

因此，下一动作由“为单向效应估计整理输入”改为“核对双向识别所需的信息，再决定是否比较两个方向”。评价也由单向效应大小与不确定性，扩展到两个方向的关联模式及其假设是否足以区分方向。这个变化来自研究目标；更多同方向样本只处理其中一部分需要。

## 将两种变化写进论证

据此可将初稿改写为：

> 要估计同一个暴露 A 对结局 B 的效应，先检查可用资料。有同一研究的个体层资料时，可在明确模型与工具条件后考虑个体层估计；暴露与结局仅在独立研究中测量时，可考虑两样本设计，并核对资料是否支持同一目标。扩大样本的建议用于改善相应模型下的精度，工具绕过暴露作用于结局的证据则要求重新审视识别条件。若研究目标改为区分 A 与 B 的方向，还须核对两侧工具的主要作用及其相互关系，再比较双向关联模式；单向估计的窄区间尚未回答这一新问题。

新段落增加了“资料形式—估计路线—识别条件”和“目标变化—所需信息—评价重选”。本例交付的是输入与目标导览；实际因果估计、估计量性能比较和方向验证各自需要相应材料与结果。

## 三种缺口，分别交付

| 发现什么 | 本轮动作与产物 | 当前回答的范围与下一出口 |
|---|---|---|
| 两样本或双向条件已经读过，初稿只有名称 | 整理原文，形成上面的新段落；新增下载可为零 | 完成输入与目标的解释；具体估计量比较仍按其证据处理 |
| 设想需要某项估计量比较，但关键原件不可得 | 尝试合格作者稿、协议或等价原始证据；交付实际阅读位置或缺口说明 | 取得足够依据后再完成比较，当前保留该判断与恢复条件 |
| 本轮用途只是输入与识别导览 | 交付导览并保留更宽问题的处理决定 | 读者可准备输入；若要比较性能，再建立相应阅读或验证任务 |

如果另选科学验证路线，先形成具体目标、输入、比较设计与评价；执行后才交付新的估计或比较结果。解释路线的产物可在当前范围内接受，更宽请求中尚未回答的部分继续保留。
