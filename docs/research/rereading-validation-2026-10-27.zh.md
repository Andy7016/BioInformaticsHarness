# 重读、视角切换与生物论证链：本轮研究总结

本轮把文献调研中的方法取舍接到研究者的实际问题：生物对象怎样成为观测，原始材料怎样形成特征，标签凭什么作参照，输出怎样支持下一步动作。三份已有综述完成更新指南后的重读，随后拓展到空间转录组、RNA velocity和微生物组成数据。当前接受范围是来源支持的综述解释与条件性方法选择。

## 已提供的指南与工作例

[方法取舍指南](../../core/docs/methods/guides/review-choice-synthesis.md)围绕目的、对象与信息用途、比较条件和缺口响应组织判断。作者、预期读者及当前研究任务是切换视角的入口；测量、药理、结构等角度由具体问题触发。QTL、姿态、剂量或毒性是否展开，取决于它们是否改变当前解释与选择。

交付确认并固定后，鼓励重新阅读所依赖的完整原文，明确补充材料的实际范围；整理遗漏、缺分析、注意偏窄和此前已正确的论证。新稿另存，再交给[修订与接受](../../core/docs/methods/guides/revision-responses-and-acceptance.md)处理。

[生物解释指南](../../core/docs/methods/guides/biological-explanation-and-handoff.md)将对象、特征、标签与用途接成连续论证。[Yeast工作例](../../core/examples/research-support/preparation/choice-synthesis-example/biological-argument/report.md)区分历史定位研究、上游特征与注释、现代固定档案评价以及新的候选用途，保留VAC筛选的负结果。[AF2Complex工作例](../../core/examples/research-support/preparation/choice-synthesis-example/rereading/report-v2.md)展示原文重读怎样改变局部解释，阅读边界见其配套记录。

## 案例回读与拓展结果

| 案例 | 本轮得到的结果 | 仍需随用途核查的证据 |
| --- | --- | --- |
| 已有三份综述：计算生物学深度学习、蛋白功能及相关预测、图像细胞表型 | 更新后的完整Harness实际供给并采用；原33条关系的118项要点得到112项直接或明确综合支持、6项有据等价覆盖。补足监督生成、属性／位点／关系、剂量／毒性等语境。 | 原首次成绩和截止保持；回读建立在已知旧结论上，没有估计指南的因果收益。 |
| N4：空间转录组混合spot分解与映射 | RCTD、cell2location与Tangram按目标量、参考和评价分开；定向修订后，36项要点中35项充分、1项有据等价。 | 精确参考成员、配置、新目标域性能和校准仍需相应输入与验证。 |
| N5：RNA velocity | 独立先读源建图，再对照冻结首交；45项主综述要点均有语义对应，保留首交，无必需修订。24项固定问题为20项充分、4项部分支持。 | Bergen2020正式全文与SI本轮未取得；La Manno作者稿与终版逐字等同性未确立。 |
| N6：微生物组成数据 | 独立36项主综述／SI要点与首交48项双向对应；三处局部修订已另存并获独立差异确认。 | 供体／批次及样本交集、原始特征沿革、实际零成因和部分实现问题保留。历史18项充分／6项部分支持自评未重写。 |

N4的修订来自操作角色的核查。[cell2location](https://doi.org/10.1038/s41587-021-01139-4)称若干簇未进一步分析，补表与映射图仍有相应标签，因此撤回“全部从映射输入删除”的推断。生物学后续分析、细胞级QC和最终参考成员分别解释。[RCTD](https://doi.org/10.1038/s41587-021-00830-w)的RNA混合目标与[Tangram](https://doi.org/10.1038/s41592-021-01264-7)的空间对齐／投影目标也各有评价条件。

N5沿[Bergen等2021综述](https://doi.org/10.15252/msb.202110282)及关键原研究，将RNA导数、高维方向、二维展示、时间、命运和机制分开。完整回读核实了首交已有的计数生成、校准、压力测试和红系反例；[La Manno2018](https://doi.org/10.1038/s41586-018-0414-6)与[Barile2021](https://doi.org/10.1186/s13059-021-02414-y)各按已读范围承担支持。[Bergen2020](https://doi.org/10.1038/s41587-020-0591-3)原件缺口继续限制相关判断。

N6以[Gloor等2017](https://doi.org/10.3389/fmicb.2017.02224)为主线，修订三处边界。第一，潜在抽样概率、随机计数和观测闭合比例分记，有限抽样比值不当成潜在比例的精确值。第二，[Mandal2015](https://doi.org/10.3402/mehd.v26.27663)的算术均值、期望对数目标与[Weiss2017](https://doi.org/10.1186/s40168-017-0237-y)的固定生态参数分别说明，本稿采用有依据的局部充分条件；原有条件反例继续保留。第三，完整ALR坐标保留全部相对信息，只做固定参照检验时缩小的是分析和报告范围。

N6的“20格正确保留／4格局部修订”是修订处置类别，不能换算成充分性评分。三项请求已闭合；原六项部分支持的来源与实施缺口继续保留。作者要点按语义配对，清单长短不用于估计遗漏或科学正确率。

## 四类共性怎样继续使用

| 共性 | 重读时提出的问题 |
| --- | --- |
| 目的与评价 | 读者要估什么、作何决定？同名指标或“均值”是否对应同一事件？ |
| 对象与信息用途 | 对象怎样成为一行观测？变量是潜在量、随机量还是观测量？筛选、参照与标签在哪个阶段使用？ |
| 比较条件 | 方法看到的信息、预处理、重复单位、分母及候选集合是否对齐？同数据多图或版本是否被重复累计？ |
| 缺口响应 | 先重读或重综合能否解决？何时应限域、换最近替代，何时才需要新的有辨识力的验证？ |

表示是否保留信息，与分析者实际检验和报告哪些关系，也应分开。具体速率、隔室、零模型、树权重及阈值由案例原件承担；提示用于唤起问题与选择重读位置。

## 阅读与使用边界

本页为原创总结及有归属的科学概括，配套[结构化记录](../../machine/research/rereading-validation-2026-10-27.json)区分首交、独立裁定、修订及验收。完整逐关系材料保存在私有研究档案；公开读者可沿本文原始文献与指南理解各项判断。

两例新综述的主文及全部主图、Gloor正式SI已完整阅读。微生物案例的七篇关键原研究主文、方法和全部主图图注已独立回读，必要SI按账本范围读取；Thorsen归档补图内部细节本次未取、未读。原件、论文图和第三方逐行数据没有随本次总结再分发。

本批完成文献分析、静态核查和方法取舍，尚未在新的目标数据上重跑方法或验证经验收益。进入具体课题时，先确定目标量与最弱的参照连接，再准备输入与匹配比较。
